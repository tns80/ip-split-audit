# 🧭 IP Split Audit · 代理分流一键体检工具

> **零依赖、跨平台、开箱即用**的代理分流测试与诊断工具。  
> 基于主流开源中国 IP 库自动校验，一次测试 **86 项**（多区域出口 IP、AI/热门服务真实出口、国内外主流站点、绕过域名规则的纯 IP/ASN 段），直接在窗口输出 **百分制打分 + 等级评价 + 可直接复制的规则修改方向**，并同步生成离线可视化网页报告 `report.html`。

---

## ✨ 为什么做这个工具？

常见的分流测试网页（如各种 IP 检测站）通常只有 4–10 个固定域名，很难发现以下真实问题：
1. **测不出纯 IP / GeoIP 分流是否准确**：老旧 MaxMind 库经常把腾讯 `1.12.12.12`、360 `101.198.x`、教育网等国内段误判成海外绕路，或者漏掉 Telegram DC1–DC5 纯 IP。
2. **被 `dns-hijack: any:53` 欺骗**：用 53 端口测港台/国内 DNS 会被本地代理内核直接劫持返回几毫秒延迟，看不出真实分流。本工具所有纯 IP 全部采用 **443 / 80 端口 + 3 次采样取中位数**，彻底避开 53 端口劫持与单包抖动。
3. **只给一堆 IP 不给结论**：新手看完仍然不知道分流算不算优秀、该怎么改规则。本工具直接输出 **0–100 综合评分 + 5 维体检条 + 人话修改建议 + 可复制 YAML 规则**。

## 🚀 快速开始（零依赖，仅需 Python 3.8+）

无需 `pip install` 任何第三方库，下载即可直接运行：

### 方式一：Windows 用户双击运行（最简单）
1. 下载本项目压缩包或 `git clone` 到本地
2. 双击运行 **`run_windows.bat`**
3. 约 15–25 秒后，终端窗口直接展示体检评分与修改方向，并自动在浏览器打开可视化报告 `report.html`

### 方式二：命令行运行（Windows / macOS / Linux）
```bash
git clone https://github.com/tns80/ip-split-audit.git
cd ip-split-audit

# 默认运行（白名单模式：确定国内直连，不确定走代理；窗口展示总评 + 修改方向 + 分类汇总）
python3 ip_split_audit.py

# 跑完自动打开可视化网页报告 report.html
python3 ip_split_audit.py --open

# 在终端同时打印全部 86 项详细测试表
python3 ip_split_audit.py --detail

# 切换为黑名单模式评分（受限走代理，其余直连）
python3 ip_split_audit.py --mode blacklist

# 手动指定本地代理端口（默认自动识别系统代理 / 环境变量 / TUN / Fake-IP）
python3 ip_split_audit.py --proxy http://127.0.0.1:7890

# 快速查询单个 IP 是否命中主流中国大陆 IP 库
python3 ip_split_audit.py --check-ip 1.12.12.12
```

## 📚 内置校验与推荐的主流开源 IP 库

本工具首次运行会自动拉取并本地缓存最新中国大陆 IPv4 CIDR 库（按顺序自动兜底）：
1. [gaoyifan/china-operator-ip](https://github.com/gaoyifan/china-operator-ip) — 基于真实 BGP 路由表每日更新，国内运营商覆盖最精准
2. [Loyalsoldier/geoip](https://github.com/Loyalsoldier/geoip) — IPIP.net + MaxMind 融合库
3. [17mon/china_ip_list](https://github.com/17mon/china_ip_list) — IPIP.net 维护的中国 IP 段列表

如在 Clash/Mihomo 或 sing-box 中配置白名单规则，也强烈推荐搭配 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat) 使用。
